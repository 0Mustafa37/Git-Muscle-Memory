IDEA 1

A commit is a photo

A full snapshot of the project plus a pointer to its parent. History is a chain of photos.

IDEA 2

A branch is a sticky note

A label pointing at one commit. It slides forward when you commit. HEAD = "you are here".

IDEA 3

Three places for files

Working dir → staging (the cart) → repo (the album). Plus origin, the album on the server.

IDEA 4

Every command does one of two things

It moves changes between those places, or it moves a sticky note around the graph.

Moving changes

git statusWhere is everything? Run it constantly.
git add f / .Working dir → staging
git commit -m ""Staging → new commit
git commit -am ""Stage tracked files and commit
git diffWorking dir vs staging
git diff --stagedStaging vs last commit

Moving sticky notes

git switch -c xCreate branch x here and move onto it
git switch xMove HEAD to branch x
git merge xJoin x's history into your branch
git rebase mainReplay your commits on top of main
git branch -d xRemove the label (commits stay)
git log --oneline --graph --allDraw the whole graph

Undo ladder

git restore --staged fUnstage, keep the edit
git restore fDiscard the edit (careful)
git reset --soft HEAD~1Undo commit, keep changes staged
git reset HEAD~1Undo commit, keep changes unstaged
git reset --hard HEAD~1Undo commit and wipe changes
git revert <hash>New commit that cancels an old one. Safe after push.
git commit --amendRedo the last commit
git reflogEvery place HEAD has been. Your safety net.

Teamwork

git push -u origin xUpload and remember the upstream
git fetchDownload only. Changes nothing of yours.
git pullfetch + merge
git pull --rebasefetch + rebase (straight history)
git stash / popPark unfinished work, bring it back

Two rules

Never rebase or reset commits other people already pulled. A rejected push means: pull first.
